# FileViewer

跨平台 Avalonia 檔案預覽與處理工作站。

## 下載

請從 [Releases](https://github.com/huang1988pioneer/FileViewer/releases) 下載與系統相符的自包含版本：

- `FileViewer-win-x64.zip`：Windows 10／11（x64）
- `FileViewer-osx-arm64.zip`：Apple Silicon Mac
- `FileViewer-osx-x64.zip`：Intel Mac
- `FileViewer-linux-x64.zip`：64 位元 Linux

解壓縮後直接執行 `FileViewer`（Windows 為 `FileViewer.exe`）。macOS 首次開啟可能需要在「系統設定 → 隱私權與安全性」確認允許未簽署應用程式。
